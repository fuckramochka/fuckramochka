### 🔭 Featured Project

#### 🌸 [Haruka](https://github.com/fuckramochka/haruka)
> *A modern, engine-first runtime for Telegram userbots.*

<p align="left">
  <img src="https://img.shields.io/badge/Python-3.10+-3776AB?style=flat-square&logo=python&logoColor=white" alt="Python 3.10+" />
  <img src="https://img.shields.io/badge/License-AGPL--3.0-blue?style=flat-square" alt="AGPL-3.0" />
  <img src="https://img.shields.io/badge/Engine-Transactional%20Hotload-purple?style=flat-square" alt="Engine" />
</p>

* **⚙️ Core Engine:** Transactional module hot-loading, single centralized command bus, SQLite persistence.
* **🛡️ Extensibility:** Stable public `haruka.api` SDK + direct `haruka.tl` MTProto access through Kurigram.
* **✨ Control Center:** Polished inline UI shell, live diagnostics and feature gates.
* **🚀 Quick Setup:** Cross-platform installers with interactive browser onboarding wizard.

git clone https://github.com/fuckramochka/haruka.git
